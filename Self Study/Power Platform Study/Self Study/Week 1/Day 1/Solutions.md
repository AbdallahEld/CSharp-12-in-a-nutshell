solution is used to transfer apps and components from an Environment to another or to apply a set of customizations to existing apps. A solution can contain more than one app as well as other components such as tables , web resources , flows , etc
# Two Types of solutions 

| Feature                 | Unmanaged Solutions                                                                              | Managed Solutions                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| Primary<br>Purpose      | Development, customization, and<br>backing up source files                                       | Production deployment and<br>distribution.                                         |
| Editing<br>Capabilities | Fully editable; you can add, remove or<br>modify components directly.                            | Locked: direct edits are blocked                                                   |
| Deletion<br>Behavior    | Deleting the solution only removes the<br>wrapper; your assets remain in<br>the default solution | Deleting the solution cleanly <br>removes all the components<br>included within it |
| Export<br>Options       | Can be exported as either Managed or<br>Unmanaged                                                | Cannot be exported out of the<br>environment where it was<br>imported              |
# Default Solution
Power Apps provides you with the following default unmanaged solutions:

- **Common Data Service Default Solution**. and its available for makers to use by default for their customization in an environment
  
- **Default Solution**. Special solution that contains all components in the system.
# Things you can do with solutions
- **Import Solution**
- **New Solution**
- **Open AppSource**
- **Publish all customization** : where it active all solution components you created
- **See history**: View details about solution operations
- **Connect to Git**: Source control integration allows to sync solutions and solution objects across one or more Dataverse environments
